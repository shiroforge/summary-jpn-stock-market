# 画面設計（DESIGN）

プロダクト名: **大引けノート**（引け後に1ページで相場を振り返るノート）

## 方針
- 最初の画面で「今日は上げたか下げたか、何が主導したか」がわかること。詳細は下にスクロールして見る。
- 数字が主役。等幅の数字（IBM Plex Mono、tabular-nums）で桁をそろえる。
- 色は「上昇・下落」の意味にだけ使う。アクセント色（藍）はリンクや操作できる部分に限る。
- JS なしでも全部読める（ツールチップ・タブ・色の切り替えだけがJS）。

## トークン
| 名前 | ライト | ダーク | 用途 |
|---|---|---|---|
| bg | #F3F5F8 | #0E1219 | ページの背景（わずかに藍寄りのグレー） |
| surface | #FFFFFF | #161B24 | タイル・カード |
| ink / ink-2 / muted | #141922 / #465064 / #778097 | #E6E9EF / #A9B0BF / #7C8497 | 文字 |
| line | #DEE2E9 | #272E3B | 罫線 |
| accent（藍） | #28487C | #8FB0E6 | リンク・選択状態 |
| red | #C4382F | #F0695C | 上昇（既定）|
| green | #1A7C55 | #45C08B | 下落（既定）|
| ヒートマップ | red-1..3 / green-1..3 / neutral | 同左（暗色版） | ±0.25% / ±1% / ±2% で3段階 |

上昇色は `data-updown="jp"`（上昇=赤、既定）と `"us"`（上昇=緑）で入れ替わる。閲覧者ごとに localStorage に保存する。

## 書体
- 見出し: Zen Kaku Gothic New 700/900
- 本文: BIZ UDPGothic 400/700（UD書体で数字や記号が読みやすい）
- 数字・コード: IBM Plex Mono 400–600

## レイアウト
- 最大幅 1120px、左右の余白 16px。スマホ幅（400px前後）では1カラム、国内指数タイルは2列。
- 上部固定バー: ブランド名、前後の営業日・アーカイブへの移動、上昇色の切り替え
- 各セクションは「見出し＋2pxの下線」で区切る。カードの枠は指数タイルと騰落バーだけに使う。

## コンポーネント
| 名前 | 内容 |
|---|---|
| 指数タイル | 名前・ETF代用バッジ／終値／前日比＋騰落率のピル／20日スパークライン（終点を強調）／5日・20日の騰落率。左端の3pxの帯で上昇・下落を示す |
| 騰落バー | 値上がり・変わらず・値下がりの積み上げ（2pxの隙間）と、各数値・騰落レシオ・年初来高安 |
| 横棒（ゼロ中心） | 33業種・テーマで共通。左右対称の軸（1, 1.5, 2, 3, 4, 5…%）。ホバー／フォーカスで中央値・上昇下落数・牽引銘柄を表示 |
| テーマ行 | 順位・名前・関連ニュース数のバッジ／横棒／騰落率／上昇数。クリックで構成銘柄のチップを開く |
| ヒートマップ | 20営業日×(33業種 or テーマ)。セルにカーソルを合わせると値を表示。行の見出しは横スクロールしても固定 |
| ランキング表 | コード／銘柄名＋業種／騰落率（売買代金は億円表示） |
| 海外表 | 名前／終値／前日比／5日／20日／スパークライン／基準日（スマホではスパークラインと基準日を隠す） |
| ニュース | 見出し（リンク）／出典・時刻・テーマタグ |
