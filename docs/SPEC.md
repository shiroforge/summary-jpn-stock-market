# 機能仕様（SPEC）

対象: 東証の引け後サマリを **Web ページ（GitHub Pages）** に出し、**Discord** に要約とURLを送る。
データ契約: `src/jpmarket/models.py` の `DailySummary`（D-02）。

---

## 1. 実行タイミングと入力

| 項目 | 仕様 |
|---|---|
| 実行 | 平日 15:47 JST（1回目、配信は16:00前後）→ 16:33 → 17:33 JST（最終）、22:07 JST に夜間更新。早い回はデータが不完全なら見送る（D-22） |
| 営業日判定 | 土日・祝日（jpholiday）・12/31〜1/3 は実行しない |
| 何度実行しても同じ結果 | 同じ日付の `data/daily/YYYY-MM-DD.json` があり、欠損がなければスキップ。`--force` で作り直す |
| 鮮度チェック | 日経平均の最終日付 ≠ 対象日 → 終了コード 75（再試行してよい失敗） |

## 2. データ取得（collect）

| データ | 取得元 | 頻度 | 備考 |
|---|---|---|---|
| 指数・為替・海外・商品 | yfinance（`config/indices.yaml`） | 日次（直近30日分） | |
| TOPIX | Yahoo!ファイナンス（日本版）の `998405.T` ページ | 日次1回 | D-03。失敗したら推計値 |
| 銘柄マスタ | JPX `topixweight_j.csv` | 月1回（キャッシュ） | コード・銘柄名・33業種・ウエイト |
| 個別株の日足 | yfinance | 日次（直近5営業日分） | 100銘柄ずつ・欠けた分を再取得（D-05） |
| 株価履歴キャッシュ | `data/prices/close.parquet` など | 日次で追記 | 20日推移・騰落レシオ・年初来高安の計算に使う |
| 17業種ETF | yfinance 1617〜1633.T | 日次 | |
| テーマ銘柄 | yfinance（`config/themes.yaml`） | 日次 | TOPIX外の銘柄は追加で取得 |
| ニュース | RSS（`config/news_feeds.yaml`） | 日次 | 前営業日の15:30 JST 以降の見出し |

## 3. 集計（analyze）

- **Quote**: 終値、前日比、騰落率、5日・20日の騰落率、直近20本のスパークライン、基準日（海外は前日付になる）
- **33業種**: D-04 の加重平均騰落率、中央値、上昇・下落数、TOPIXに占める比率、leaders/laggards（寄与度＝騰落率×ウエイトの上位・下位3銘柄）
- **テーマ**: 構成銘柄の騰落率の単純平均、上昇比率、全メンバー（騰落率の降順）、関連ニュース数
- **騰落**: TOPIX構成銘柄の値上がり・値下がり・変わらずの数。騰落レシオ(25日) = Σ値上がり数/Σ値下がり数×100。年初来高値・安値の更新数（キャッシュが十分にある場合のみ）
- **ランキング**: 値上がり率・値下がり率・売買代金（終値×出来高で近似）の上位10銘柄。値上がり率・値下がり率は売買代金10億円以上に限る（小型株のノイズ除去）
- **履歴**: 33業種・テーマの直近20営業日の日次騰落率（ヒートマップ用）
- **コメント**（ルールベース）: 「日経平均は±x.xx%、TOPIXは±y.yy%。A・Bが上昇を主導し、Cが最も弱い。テーマでは「D」が強い。」を基本形とし、値上がり銘柄の比率が極端なとき（80%以上・20%以下）は「全面高/全面安」を付け加える
- **警告**: カバー率95%未満、TOPIX が推計値になった、ニュースの取得に失敗したフィードがある、など

## 4. 出力

### 4.1 サイト構成
```
site/
  index.html            → 最新日へリダイレクト（meta refresh + リンク）
  YYYY-MM-DD/index.html → 日次ページ（CSS/JSはインライン化し、1ファイルで完結）
  archive/index.html    → 月ごとのカレンダー一覧（日経平均の騰落率で色分け）
  trends/index.html     → Phase 3: 長期のヒートマップとテーマの推移
  data/YYYY-MM-DD.json  → 生データ（任意）
```

### 4.2 日次ページ（DESIGN.md 参照）
① 日付・警告・コメント → ② 国内指数タイル＋騰落 → ③ 33業種 → ④ テーマ → ⑤ 20日ヒートマップ → ⑥ ランキング → ⑦ 海外・為替・商品 → ⑧ ニュース → フッター（出典・免責）

### 4.3 Discord 通知（1通の Embed、以下の数値は例）
```
📈 2026/09/25(金) 大引け
日経平均 66,364 (+1.23%) ｜ TOPIX 4,128.59 (+1.31%)
▲ 上位業種: 銀行業 +4.06% / 証券 +2.09% / その他金融 +1.84%
▼ 下位業種: 情報・通信 -0.79% / 鉱業 -0.22% / その他製品 +0.04%
🔥 強いテーマ: 銀行 +3.9% / 半導体 +2.1% / 防衛 +1.8%
📰 日銀、年内の追加利上げを示唆 … ほか2件
👉 https://<user>.github.io/<repo>/2026-09-25/
```
- Embed の左端の色: 日経平均が上昇なら赤系、下落なら緑系（上昇色の設定に合わせる）
- 失敗時: 「⚠️ 2026-09-25 の生成に失敗: <要約>」と Actions の実行URL を送る
